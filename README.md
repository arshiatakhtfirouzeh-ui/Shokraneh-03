# شکرانه — دفتر شکرگزاری و آرامش

برنامه‌ای آروم و مدرن برای شکرگزاری روزانه، به زبان فارسی و انگلیسی. با **پایتون و Flet** نوشته شده و از یک کد هم روی **کامپیوتر** اجرا می‌شه و هم می‌شه ازش **APK اندروید** ساخت.

## چی داخلشه؟

| بخش | توضیح |
|---|---|
| شکرگزاری صبح | ۷ سؤال (۵ نعمت، ۳ ویژگی خودم، ۳ اتفاق خوب، احساس امروز، ۳ هدف، کار خوب برای دیگران، جمله‌ی انگیزشی) |
| شکرگزاری شب | ۹ سؤال (۵ اتفاق خوب، کی خوشحالم کرد، افتخار، یادگیری، اشتباه و درسش، کار خوب، ناراحتی و راه کنار اومدن، فردا بهتر، تشکر از خدا) |
| فضاها | آرزوها · موفقیت‌ها · صحبت با خدا · دعاها · عزیزانی که عمیق دوستشون دارم (شکرگزاری بابتشون و نبودنشون) · روزهای سخت (درسی که گرفتم) |
| نامه به خودِ آینده | خودت زمان بازشدن رو انتخاب می‌کنی؛ سر وقت یادآوری می‌شی |
| پیشرفت | هر روز انرژی/حال ۱ تا ۱۰، نمودار، و در پایان ماه مرور ماهانه با پیشنهادهای بهتر شدن |
| پیام‌ها | گزارش هفتگیِ مهربون و صادق (نقد سازنده) + مرور ماهانه |
| تقویم | شمسی/میلادی، نقطه‌ی فعالیت هر روز، دیدن و ویرایش نوشته‌ی هر روز |
| تنظیمات | زبان، تقویم، شروع هفته، تم روشن/تیره/رنگ اصلی، یادآورها، هوش مصنوعی، رمز، پشتیبان‌گیری |
| چند پروفایل | هر نفر نوشته‌های جدا و مخصوص خودش رو داره |

همه‌ی نوشته‌ها **فقط روی همین دستگاه** و جدا برای هر پروفایل ذخیره می‌شن (فایل JSON با نوشتن امن و نسخه‌ی پشتیبان خودکار).

### هوش مصنوعی

* **مربی آفلاین** همیشه کار می‌کنه و گزارش هفتگی/ماهانه می‌سازه (بدون اینترنت).
* اگه بخوای، در تنظیمات می‌تونی **Anthropic (Claude)** یا هر سرویس **سازگار با OpenAI** (یا سرور محلی مثل Ollama) رو وصل کنی تا گزارش‌ها دقیق‌تر و شخصی‌تر بشن. برای این کار کلید API، و رضایت صریح خودت لازمه.
* وقتی هوش مصنوعیِ آنلاین روشنه، **متن نوشته‌های همون بازه برای ساخت گزارش به سرویس انتخابی فرستاده می‌شه** (اسم عزیزانت فرستاده نمی‌شه). کلید فقط روی همین دستگاه و داخل فایل پروفایل (رمزگذاری‌نشده) ذخیره می‌شه و در پشتیبان نمی‌آد.
* دسترسی به هر سرویس آنلاین به قوانین و مناطق پشتیبانی‌شده‌ی خودِ همون سرویس بستگی داره. اگه وصل نشد، برنامه خودکار به مربی آفلاین برمی‌گرده.
* اگه گزارش نشونه‌هایی از ناراحتی شدید ببینه، یه یادداشت حمایتی ثابت اضافه می‌کنه؛ این برنامه جای درمان یا مشاوره نیست.

### ظاهر شیشه‌ای (نسخه‌ی ۱٫۲)
- **لیکویید گلس:** پس‌زمینه‌ی رنگیِ نرم (سه درخششِ هم‌رنگ با رنگ اصلی)، کارت‌ها و دکمه‌های شفاف با لبه‌ی روشن، نوار پایینِ شناور و بلورشده که محتوا زیرش اسکرول می‌شه و پنجره‌های شیشه‌ایِ بلورشده.
- **تنظیمات ← ظاهر ← سبک ظاهر:** «شیشه‌ای» (با بلور)، «سبک» (شفاف ولی بدون بلور، برای گوشی‌های کندتر) و «ساده» (همون ظاهر ماتِ قبلی). جزیره‌ی پویا هم از همین‌جا خاموش می‌شه.

### ظاهر (نسخه‌ی ۱٫۱)
- **جزیره‌ی پویا:** یه قرصِ تیره بالای صفحه‌ی اصلی که خلاصه‌ی امروز (صبح، شب، حال، روزهای پیاپی) رو نشون می‌ده؛ بهش بزنی باز می‌شه و سه میان‌بُر می‌ده. پیام‌ها (ذخیره شد، یادآور، خطا) هم به‌جای نوار پایین، توی همین قرص ظاهر می‌شن.
- کارت خوش‌آمد گرادیانی با حلقه‌ی پیشرفت روزانه، نوار پایینِ شناور، کارت‌های نرم‌تر و دکمه‌های گرادیانی.
- **بخش «سازنده»** در تنظیمات، با نام سازنده و متن کپی‌رایت (فایل `COPYRIGHT.md` هم کنار پروژه هست).

## ۱) اجرا روی کامپیوتر

پایتون ۳.۱۲ یا بالاتر لازمه.

```bash
pip install -r requirements.txt        # یا: pip install "flet[all]>=1.1,<1.2" certifi
python tools/get_fonts.py              # اختیاری: فونت وزیرمتن (ظاهر فارسی قشنگ‌تر)
python src/main.py                     # یا: flet run src/main.py
```

داده‌ها اینجا ذخیره می‌شن: ویندوز `%APPDATA%\Shokraneh` · مک `~/Library/Application Support/Shokraneh` · لینوکس `~/.local/share/Shokraneh`.
(با متغیر محیطی `SHOKRANEH_DATA_DIR` می‌شه جاش رو عوض کرد.)

## ۲) ساختن APK با گیتهاب (بدون نصب چیزی روی کامپیوتر)

1. توی [github.com](https://github.com) حساب بساز و یه مخزن (Repository) **خصوصی** جدید بساز.
2. کل محتوای این پوشه رو داخلش بریز. **پوشه‌ی `.github` حتماً باید باشه** (پوشه‌های نقطه‌دار تو بعضی سیستم‌ها پنهانن؛ اگه از وب آپلود می‌کنی بهتره از Git یا GitHub Desktop استفاده کنی):
   ```bash
   git init && git add -A && git commit -m "Shokraneh"
   git branch -M main && git remote add origin https://github.com/<نام‌کاربری>/<مخزن>.git && git push -u origin main
   ```
3. تو مخزن برو تب **Actions** ← **Build Android APK** ← **Run workflow**.
4. ۱۵ تا ۳۰ دقیقه صبر کن. وقتی سبز شد، پایین صفحه‌ی اجرا، بخش **Artifacts** ← `shokraneh-apk` رو دانلود کن و از حالت زیپ دربیار.
5. فایل `.apk` رو بفرست به گوشی و نصب کن (اندروید می‌پرسه «نصب از منبع ناشناس» رو اجازه بدی).

نکته: اگه یه برچسب مثل `v1.0.0` بزنی (`git tag v1.0.0 && git push --tags`)، APK به‌صورت **Release** هم منتشر می‌شه.

APK ساخته‌شده برای استفاده‌ی شخصی و نصب مستقیم روی گوشی مناسبه. برای انتشار در فروشگاه‌ها باید امضای اختصاصی (signing) تنظیم کنی؛ راهنمای ساخت اندروید رو در مستندات Flet ببین.

## ۳) یادآورها و اعلان‌ها — لطفاً صادقانه بخون

* **روی کامپیوتر**: اعلان سیستم‌عامل (ویندوز/مک/لینوکس با `notify-send`) وقتی برنامه باز (یا کوچک‌شده) باشه.
* **APK پیش‌فرض**: افزونه‌ی اعلان بومی اندروید توش **نیست** (چون به دست‌کاری Gradle نیاز داره و هنوز آلفاست). پس یادآور صبح/شب و رسیدن نامه‌ها **فقط وقتی برنامه باز است** با پنجره/بنر داخل برنامه نشون داده می‌شن؛ و هر بار که برنامه رو باز کنی، نامه‌های رسیده و گزارش‌های آماده بهت نشون داده می‌شن.
* **نسخه‌ی آزمایشی با اعلان واقعی**: workflow دوم (`Build Android APK (experimental - with notifications)`) با افزونه‌ی [`flet-android-notifications`](https://pypi.org/project/flet-android-notifications/) APK می‌سازه تا حتی وقتی برنامه بسته است اعلان بیاد. این مسیر **آزمایش نشده** و ممکنه به دست‌کاری نیاز داشته باشه؛ اگه شکست خورد، نسخه‌ی پیش‌فرض همچنان کامل کار می‌کنه. بعد از نصب، در «تنظیمات ← یادآورها» روی «اجازه‌ی اعلان» بزن. روی بعضی گوشی‌ها (شیائومی، سامسونگ، …) باید برنامه رو از «صرفه‌جویی در باتری» مستثنی کنی.

## ۴) امنیت و حریم خصوصی

* **رمز (PIN ۴ رقمی)** فقط **صفحه‌ی برنامه رو قفل می‌کنه** (و وقتی برنامه به پس‌زمینه می‌ره دوباره قفل می‌شه). فایل‌ها **رمزگذاری نمی‌شن**؛ کسی که به فایل‌های دستگاه دسترسی کامل داشته باشه می‌تونه بخونتشون. رمز فراموش‌شده قابل بازیابی نیست (راهش پاک‌کردن پروفایل و بازیابی از پشتیبانه).
* **پشتیبان‌گیری**: تنظیمات ← پشتیبان‌گیری و داده‌ها. «ذخیره‌ی فایل» و «بازیابی از فایل»؛ اگه انتخاب فایل روی دستگاهت کار نکرد، گزینه‌ی «متن» (کپی/چسباندن) همیشه هست. فایل پشتیبان رمزگذاری نیست؛ جای امنی نگهش دار. کلید API و تنظیمات توش نیست.
* ردیابی، حساب کاربری یا تبلیغ وجود نداره. تنها ارتباط اینترنتی، گزارش‌های هوش مصنوعیِ آنلاین است و فقط وقتی که خودت روشنش کنی.

## ۵) فونت

فونت [وزیرمتن](https://github.com/rastikerdar/vazirmatn) (لایسنس SIL OFL) در ساخت گیتهاب خودکار دانلود می‌شه. روی کامپیوتر با `python tools/get_fonts.py`. اگه نباشه، برنامه از فونت سیستم استفاده می‌کنه.

## ۶) اگه چیزی درست کار نکرد

* **راست‌به‌چپ به‌هم‌ریخته بود؟** تنظیمات ← ظاهر و زبان ← «اصلاح چیدمان راست‌به‌چپ».
* اگه برنامه موقع شروع خطا بده، به‌جای صفحه‌ی خالی متن خطا نشون می‌ده؛ همون رو برام بفرست.
* ساخت APK شکست خورد؟ لاگ مرحله‌ی «Build APK» رو بفرست.

## ۷) برای برنامه‌نویس‌ها

```
src/main.py                 نقطه‌ی شروع
src/shokraneh/              store, jalali, analytics, coach (مربی آفلاین), ai, reports, reminders, notify, i18n ...
src/shokraneh/ui/           app (کنترلر)، kit (اجزای ظاهری)، theme، compat، files، screens/
tests/                      pytest — منطق + شبیه‌ساز سخت‌گیر Flet برای همه‌ی صفحه‌ها
tools/                      get_fonts, make_icon, patch_android
```

```bash
pip install pytest && pytest -q      # ۱۱۰+ تست؛ بدون نیاز به Flet واقعی
```

### محدودیت‌هایی که باید بدونی

* این کد **با Flet واقعی اجرا نشده** (محیط ساختش اینترنت/نصب بسته نداشت). منطق برنامه با ۱۱۰+ تست و یه شبیه‌ساز سخت‌گیرِ Flet بررسی شده (ساخت همه‌ی صفحه‌ها در هشت حالت زبان/تم/جهت، زدن روی همه‌ی دکمه‌ها، مسیرهای کامل کاربر، بررسی چیدمان)، اما شبیه‌ساز جای اجرای واقعی رو نمی‌گیره: ممکنه فاصله‌ها، فونت یا یه جزئیات ظاهری نیاز به تنظیم داشته باشه.
* لایه‌ی `ui/compat.py` تفاوت‌های کوچک بین نسخه‌های Flet (پارامتر یا آیکون ناموجود) رو تحمل می‌کنه و فقط ظاهر رو ساده‌تر می‌کنه، نه اینکه برنامه رو از کار بندازه. نسخه‌ی Flet روی `>=1.1,<1.2` قفله.
* انتخاب فایل/کلیپ‌بورد (پشتیبان‌گیری) وابسته به API افزونه‌های Flet است؛ مسیر متنیِ جایگزین همیشه کار می‌کنه.
* تقویم شمسی با الگوریتم داخلی محاسبه می‌شه (تست‌شده برای تبدیل‌های کلیدی)؛ تعطیلات رسمی نشون داده نمی‌شن.
